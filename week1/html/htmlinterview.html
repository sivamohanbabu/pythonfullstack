HTML Interview Questions & Practice

Interactive Q&A and practice problems for freshers and experienced developers

Freshers HTML Questions

1. What is HTML?

HTML (HyperText Markup Language) is the standard markup language for creating web pages.

2. What are HTML tags?

Tags are elements in HTML enclosed in angle brackets < >, like <p>, <a>, <h1>.

3. Difference between <div> and <span>?

<div> is block-level; <span> is inline.

4. Semantic tags in HTML5?

Tags like <header>, <footer>, <article>, <section> that give meaning to content.

5. Difference between HTML4 and HTML5?

HTML5 introduces semantic tags, multimedia support, canvas, offline storage, and new form inputs.

6. Purpose of <head> tag?

Contains metadata, links to CSS/JS, and the page title.

7. Difference between <ol> and <ul>?

<ol> = ordered list, <ul> = unordered list.

8. What is an HTML attribute?

Additional information about an element, e.g., href in <a href="url">.

9. Difference between <strong> and <b>?

<strong> is semantic, <b> is just visual bold.

10. Difference between <em> and <i>?

<em> emphasizes text semantically; <i> italicizes text visually.

Experienced HTML Questions

21. New input types in HTML5?

Email, url, number, date, color, range, tel, search.

22. What is <canvas>?

A container for graphics drawn via JavaScript.

23. Difference between <section> and <article>?

<section> groups related content; <article> is independent content.

24. Difference between <audio> and <video>?

<audio> = sound; <video> = video content.

25. LocalStorage vs sessionStorage?

localStorage persists until cleared; sessionStorage persists until tab closes.

26. What are data-* attributes?

Custom attributes to store data, e.g., data-id="123".

27. <progress> vs <meter>?

<progress> shows task progress; <meter> shows measurement within a range.

28. Async vs defer in <script>?

Async loads JS asynchronously; defer waits until HTML parsing completes.

29. Purpose of <template>?

Holds content for JS to render later; not displayed by default.

30. Deprecated HTML tags?

<center>, <font>, <big>, <strike>, <frame>.

HTML Practice Problems

  1. Create a personal portfolio page using semantic HTML5 tags.
  2. Create a form that validates email and number input using HTML5 attributes.
  3. Create a table showing product details with <thead>, <tbody>, <tfoot>.
  4. Embed audio and video files in a webpage.
  5. Draw a circle and rectangle using <canvas>.
  6. Create a collapsible FAQ section using <details> and <summary>.
  7. Highlight text using <mark> and show deleted text using <del>.
  8. Store user input in localStorage and display it on page reload.
  9. Make a responsive webpage using <meta viewport> and semantic tags.
  10. Create a progress bar showing task completion.
  11. Build a navigation menu using <nav> with 3+ links.
  12. Embed an image with <figure> and <figcaption>.
  13. Use <meter> to show system or CPU usage (simulation).
  14. Use new HTML5 input types: date, color, range, tel.
  15. Create a template card using <template> and clone it using JS.
