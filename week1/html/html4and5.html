HTML4 vs HTML5 Features

This page shows the main features of HTML4 and HTML5 with examples.

HTML4 Features

HTML4 was the standard before HTML5. It has the following features:

  • Structuring content with <div> and <span> instead of semantic tags
  • Tables for layout as well as data
  • Forms with basic input types: text, password, checkbox, radio, submit
  • Limited multimedia support (requires plugins like Flash for audio/video)
  • Limited semantic elements; mostly structural tags like <div> and <span>
  • Frames and framesets for dividing the page

HTML5 Features

HTML5 is the latest standard and includes new features:

  • New semantic tags: <header>, <footer>, <article>, <section>, <aside>
  • Enhanced forms with new input types: email, url, date, color, range, number
  • Multimedia support: <audio> and <video> without plugins
  • Canvas and SVG for drawing and graphics
  • Local storage and offline capabilities (via JavaScript, not HTML-only)
  • Details and summary for collapsible content
  • Improved accessibility and mobile support
