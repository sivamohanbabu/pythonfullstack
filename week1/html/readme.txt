Days 1–5: Web Development Basics
Day 1: Introduction to HTML & HTML Structure

HTML (HyperText Markup Language) is the standard language used to create web pages. It structures the content on the web.

Basic HTML Structure:
Key Elements:

<!DOCTYPE html> – Declares the HTML version.

<html> – Root element.

<head> – Contains meta-information like title, character set, and links to CSS.

<body> – Contains visible content like headings, paragraphs, images, links, etc.

Day 2: Semantic Tags

Semantic tags give meaning to web content, making it more readable and SEO-friendly.

Common Semantic Tags:

<header> – Represents the page header.

<nav> – Navigation links.

<main> – Main content of the page.

<section> – Defines a section of content.

<article> – Independent piece of content.

<aside> – Sidebar or related content.

<footer> – Footer content.

Day 3: Forms

Forms are used to collect user input.

Common Form Elements:

<form> – Container for the form.

<input> – Single-line input (text, email, password, checkbox, radio).

<textarea> – Multi-line input.

<select> – Dropdown menu.

<button> – Submit or action button.

<label> – Labels for input fields.


Day 4: Tables

Tables display data in rows and columns.

Common Table Elements:

<table> – Container for the table.

<tr> – Table row.

<th> – Table header.

<td> – Table data cell.

<caption> – Table title.


Day 5: Images and Links

Images are added using <img> tag:

src – Path to the image file.

alt – Alternative text (important for accessibility).

width & height – Image size.

Advanced HTML – Theory & Examples
1. Multimedia Elements

Theory:

<audio> and <video> tags allow embedding media directly in a webpage.

controls attribute adds play, pause, and volume buttons.

<source> allows multiple formats for compatibility.
HTML5 Form Enhancements

Theory:

HTML5 introduced new input types like email, url, date, color, range, number.

New attributes: required, min, max, pattern, placeholder, autofocus.

These improve validation and user experience without JavaScript.


Semantic & Structural Tags

Theory:

Semantic tags improve readability, accessibility, and SEO.

Examples: <article>, <aside>, <figure>, <figcaption>, <time>, <details>, <summary>.

<figure> + <figcaption> groups images with captions.

<details> + <summary> allows collapsible content.

Advanced Links and Navigation

Theory:

Use target="_blank" to open links in new tabs.

rel="noopener noreferrer" improves security for external links.

Anchor links navigate within the same page.

download attribute lets users download files directly.

Advanced Tables

Theory:

<thead>, <tbody>, <tfoot> organize tables.

colspan and rowspan merge cells across columns or rows.

<caption> gives a title to the table.

HTML Templates

Theory:

<template> stores reusable content that is not rendered until used (usually with JavaScript).

Useful for repeated sections like cards or lists.

Metadata for SEO

Theory:

<meta> tags provide info for search engines and browsers.

Common types: description, keywords, author, viewport.
