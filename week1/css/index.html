CSS Fundamentals & Layouts

1. CSS Fundamentals

CSS (Cascading Style Sheets) is used to style HTML elements. You can control colors, fonts, spacing, layout, and much more.

Syntax:

selector {
    property: value;
    property: value;
}

Example:

p {
    color: blue;
    font-size: 16px;
}

2. CSS Box Model

Every HTML element is a rectangular box consisting of:

  • Content
  • Padding
  • Border
  • Margin

Example:

Box 1
Box 2
Box 3
.box {
    width: 150px;
    padding: 20px;
    border: 5px solid #333;
    margin: 10px;
}

3. Flexbox

Flexbox is a layout model that allows you to arrange elements in rows or columns easily.

Flex 1
Flex 2
Flex 3
.flex-container {
    display: flex;
    justify-content: space-around;
    align-items: center;
}
.flex-item {
    background-color: #ff5722;
    padding: 20px;
    border-radius: 5px;
}

4. Responsive Layouts

Responsive design ensures web pages look good on all devices (desktop, tablet, mobile).

Item 1
Item 2
Item 3
Item 4
.responsive-container {
    display: flex;
    flex-wrap: wrap;
    gap: 10px;
}
.responsive-item {
    flex: 1 1 200px;
    padding: 20px;
    text-align: center;
}
@media(max-width:600px){
    .flex-container {
        flex-direction: column;
    }
}
