CSS Interview Questions & Answers

Interactive Q&A for freshers and experienced developers

CSS Questions for Freshers

1. What is CSS?

CSS (Cascading Style Sheets) is used to style HTML elements by controlling layout, colors, fonts, spacing, and more.

2. Difference between inline, internal, and external CSS?

Inline CSS: using the style attribute in HTML. Internal CSS: inside <style> in head. External CSS: in a separate .css file linked via <link>.

3. What are selectors in CSS?

Selectors are patterns used to select elements you want to style. Examples: element selectors, class selectors, ID selectors.

4. Difference between relative, absolute, and fixed positioning?

Relative: moves relative to its normal position. Absolute: positions relative to the nearest positioned ancestor. Fixed: stays in place relative to viewport.

5. What is the difference between em, rem, px, % units?

px: pixels, em: relative to parent font-size, rem: relative to root font-size, %: percentage relative to parent.

CSS Questions for Experienced Developers

21. Difference between relative, absolute, fixed, and sticky positioning?

Sticky is relative until a certain scroll position, then it becomes fixed.

22. What is the difference between inline, inline-block, and block elements?

Inline: only takes as much width as content; Block: takes full width; Inline-block: behaves like inline but allows width and height.

23. Difference between flexbox and CSS grid?

Flexbox: one-dimensional layout (row/column), Grid: two-dimensional layout (rows and columns).

24. What are pseudo-classes and pseudo-elements?

Pseudo-class: styles elements in a special state (:hover, :first-child). Pseudo-element: styles a part of element (::before, ::after).

25. How does z-index work?

z-index determines stack order of positioned elements (higher z-index appears on top).

26. What is the difference between relative units (em/rem) and absolute units (px)?

Relative units scale based on parent (em) or root (rem), absolute units like px do not scale.

27. What is the difference between visibility:hidden and display:none?

visibility:hidden hides the element but keeps its space, display:none removes it completely from layout.

28. Difference between CSS transitions and animations?

Transitions: change property over time triggered by event (hover). Animations: full keyframe animations, independent of events.

29. What are media queries?

Media queries allow responsive design by applying CSS based on device width, height, orientation, etc.

30. How to center a div vertically and horizontally using flexbox?

Use display:flex; justify-content:center; align-items:center; height:100%;
