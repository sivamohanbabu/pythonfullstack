Closures

A closure is a function that remembers the lexical environment where it was created. Useful for data privacy and factories.

// counter factory: closure keeps `count` private
function makeCounter(init = 0) {
  let count = init;
  return {
    inc() { count++; return count; },
    dec() { count--; return count; },
    value() { return count; }
  };
}
const c = makeCounter(5);

Prototypes

All objects inherit from a prototype. Use prototypes to share methods across instances.

// constructor + prototype
function Person(name) {
  this.name = name;
}
Person.prototype.greet = function() {
  return `Hi, I'm ${this.name}`;
};
const p = new Person('Maya');

Classes & this

ES6 classes are syntactic sugar over prototypes. this depends on how a function is called.

class Animal {
  constructor(name){ this.name = name; }
  speak(){ return `${this.name} makes a noise`; }
}
const a = new Animal('Dog');

// `this` example: bound vs unbound
const obj = { x: 10, getX(){ return this.x; } };
const unbound = obj.getX; // calling unbound loses `this`

Promises

Promises represent future values. Use .then / .catch or async/await.

// create a promise which resolves after a delay
function delay(ms, value) {
  return new Promise((resolve) => setTimeout(() => resolve(value), ms));
}

Async / Await & Fetch API

async/await is syntactic sugar over promises. fetch calls network resources (CORS applies).

// sample async function to fetch a JSON resource
async function fetchTodo() {
  const res = await fetch('https://jsonplaceholder.typicode.com/todos/1');
  const json = await res.json();
  return json;
}
