JavaScript CORE Concepts

1. Hoisting

Hoisting allows variable and function declarations to be moved to the top of their scope during the compile phase.

// Example
console.log(a); // undefined
var a = 10;

hello(); // Works
function hello() {
  console.log("Hello World");
}

2. Scope

Scope defines where variables and functions are accessible — Global, Function, or Block scope.

let x = 10;
if (true) {
  let x = 20; // block scoped
  console.log(x); // 20
}
console.log(x); // 10

3. Callbacks

A callback is a function passed as an argument to another function.

function greet(name, callback) {
  console.log("Hello " + name);
  callback();
}
function done() {
  console.log("Greeting completed");
}
greet("Arshad", done);

4. Events

Events respond to user interactions like clicks, keypress, mouseover, etc.

document.getElementById("btn").addEventListener("click", () => {
  alert("Button Clicked!");
});

5. Event Bubbling

Event bubbling occurs when an event triggers from the deepest target element and bubbles upward.

<div id="parent">
  <button id="child">Click Me</button>
</div>

6. Debouncing

Debouncing ensures a function runs only after a certain time has passed without it being called again.

function debounce(fn, delay) {
  let timer;
  return function (...args) {
    clearTimeout(timer);
    timer = setTimeout(() => fn.apply(this, args), delay);
  };
}
const handleInput = debounce(() => console.log("Typing stopped"), 500);

7. Throttling

Throttling ensures a function runs at most once in a specified time interval.

function throttle(fn, limit) {
  let wait = false;
  return function () {
    if (!wait) {
      fn();
      wait = true;
      setTimeout(() => wait = false, limit);
    }
  };
}
window.addEventListener("scroll", throttle(() => console.log("Scroll event"), 1000));

8. Timers

JavaScript provides setTimeout and setInterval for handling timed actions.

setTimeout(() => console.log("Runs after 2 seconds"), 2000);

let count = 0;
setInterval(() => {
  count++;
  console.log("Counter: " + count);
}, 1000);

9. Error Handling

Error handling allows developers to catch and handle errors gracefully using try-catch.

try {
  let num = a + 10; // error
} catch (err) {
  console.log("Error occurred:", err.message);
} finally {
  console.log("Execution complete");
}
