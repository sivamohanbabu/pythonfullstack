Python — Basics

This page covers the basic Python concepts with clear explanations and code examples.

1. Variables

Variables store data in Python.

x = 10
name = "Arshad"
price = 99.5

print(x, name, price)

2. Data Types

a = 10            # int
b = 3.14          # float
c = "Hello"       # string
d = True          # bool
e = [1,2,3]       # list
f = (1,2,3)       # tuple
g = {"a": 1}      # dict
h = {1,2,3}       # set

3. Input and Output

name = input("Enter your name: ")
print("Hello,", name)

4. Conditionals (if / elif / else)

x = 10

if x > 5:
    print("Greater")
elif x == 5:
    print("Equal")
else:
    print("Smaller")

5. Loops

For Loop:

for i in range(5):
    print(i)

While Loop:

count = 0
while count < 5:
    print(count)
    count += 1

6. Functions

def add(a, b):
    return a + b

print(add(5, 3))

7. Lists

nums = [1, 2, 3]
nums.append(4)
nums.remove(2)

print(nums)

8. Tuples

t = (1, 2, 3)
print(t[0])

9. Dictionaries

student = {"name": "Arshad", "age": 20}

print(student["name"])

student["age"] = 21

10. Sets

s = {1, 2, 3}
s.add(4)

print(s)
